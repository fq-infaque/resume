# Job Applications Log

Every application Muse submits on Fahad's behalf is recorded here, with the exact CV
PDF used for that application stored alongside.

## Conventions

- Each application gets its own folder: `applied/YYYY-MM-DD-<company>-<role>/`
  (slugs are lowercase, words separated by `-`, e.g. `applied/2026-10-03-acme-corp-vp-engineering/`)
- The CV actually submitted lives in that folder as `cv.pdf` — byte-identical to what
  the application form received. Never overwrite it after applying.
- If a tailored variant was generated for the role, the HTML source lives next to it
  as `cv-src.html` for reproducibility.
- One row per application in the table below, newest first.
